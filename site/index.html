hamcall-db

Openly-licensed amateur radio reference data, rebuilt from upstream sources and published as files you can fetch instead of APIs you have to register for.

Reflector directory

A digital-voice reflector directory for D-Star, M17, YSF, NXDN, P25 and URF, served as static JSON. No API key, no account, no rate limit — it is a file on a CDN.

Using it

Fetch api/index.json first. It lists every network with its row count and the date its data was generated, so a client can decide whether its cached copy is stale without downloading the big files. 

curl -s https://rcludwick.github.io/hamcall-db/api/index.json
curl -s https://rcludwick.github.io/hamcall-db/api/reflectors/dstar.json

Each reflector carries an id, a host and a port, plus modules where the network has them. D-Star and M17 entries also carry callsign — the name the reflector answers to on the air, which is not always its directory name. An XLX reflector is listed as XLX836 but a DExtra client must put XRF836 in its RPT1/RPT2 header, so the value is published rather than left for each client to re-derive. 

{
  "id": "XLX836",
  "callsign": "XRF836",
  "host": "45.56.69.219",
  "port": 30001,
  "country": "USA",
  "source": "xlx"
}
XRF and XLX are not the same reflectors. They share a numbering scheme and nothing else. Measured 2026-08-26, 13 of 14 sampled XRF###/XLX### pairs resolved to entirely different servers — XRF002 is xrf002.dstar.club, while XLX002 is a host in China. Both are published under their own ids and are never merged.

Refresh policy

The files are rebuilt nightly, but client_refresh_days is 7: please cache for a week. Reflector hosts move on a scale of weeks, so polling harder buys nothing and costs everyone bandwidth. The generated date reflects the data, not the build — a rebuild that finds nothing new leaves the files byte for byte unchanged.

A network whose upstream fails, or whose row count collapses, keeps its previous file rather than publishing a regression. Upstream is volunteer-run and offers no SLA, so an outage there should not blank out every client's reflector picker.

Callsign dataset

A normalized amateur licensee dataset aggregated from national regulators, published as Parquet and SQLite through GitHub Releases rather than served here — it is far too large for a static site. Separate reference datasets cover POTA parks and SOTA summits.

Licences are kept apart, deliberately

These datasets are not distributed under one licence, and combining them is the consumer's decision to make knowingly:

  • Reflector directory — CC BY 4.0. Free for commercial use. It is a separate artifact precisely so it stays that way: CC BY 4.0 forbids adding restrictions the licence grants away, so folding it into the non-commercial callsign dataset would be a licence violation, not just untidy.
  • Callsign dataset — CC BY-NC 4.0. Non-commercial, inherited from cty.dat and other upstreams.
  • OSM-derived park grids — ODbL. Share-alike, in their own files. Joining them to anything else and redistributing the result makes that result ODbL.

Build code is MIT. The published data is not — see the terms above.
